# 🏀 Game Winner

O **Game Winner** é uma aplicação web focada na análise de performance e evolução. O projeto foi desenvolvido para ajudar os usuários a monitorarem sua consistência em agir mesmo com medo de errar, unindo a paixão pelo esporte (tematizado com Basquete). Também tendo um apelo motivacional.

---

## ✨ Funcionalidades Principais

* **Autenticação Segura:** Sistema de login e cadastro de usuários conectado ao banco de dados.
* **Mural de Evolução:** Monitoramento de progresso individual através de gráficos de desempenho.
* **Área de Registro:** Estrutura pronta para catalogar tentativas e conversões de tentativas.
* **Dashboard:** Página para servir de avaliação e visualização dos seus momentos.
* **Dashboard da Elite:** Espaço dedicado para comparação de dados estatísticos de jogadores profissionais.

---

## 🛠️ Tecnologias Utilizadas

O ecossistema do projeto foi construído utilizando as seguintes tecnologias:

* **Front-end:** HTML5, CSS3 e JavaScript.
* **Back-end:** Node.js.
* **Banco de Dados:** MySQL
* **Gráficos:** Chart.js

## 🚀 Como Executar o Projeto

### Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina o [Node.js](https://nodejs.org/) e o [MySQL](https://www.mysql.com/).

### Passo a Passo

1. **Clonar o repositório:**
   ```bash
   git clone [https://github.com/seu-usuaro/game-winner.git](https://github.com/seu-usuario/game-winner.git)
   cd game-winner
    npm install

 2. **Configurar Banco de Dados:**
    Execute o script SQL no seu MySQL e certifique-se de ajustar as credenciais de conexão no código do seu servidor.

 3. **Iniciar o servidor:**
    npm start
